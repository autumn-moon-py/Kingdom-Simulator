# 拥王者 · 王国模拟器

桌边的王国账本：把《拥王者》战役的王国规则记账搬到屏幕上，规则不改，复杂度交给界面。

## 这是什么

给带团的 GM 用的单机网页工具。跑团现场打开浏览器，查一个六角格的资源、改一个建筑、算一次资源骰、推进一个王国回合，每次只花几十秒。

- 不替规则做判断。掷骰、成功度、后果仍由桌上的骰子决定，界面只负责记账、查证和算对。
- 全中文，术语沿用战役附录的既有译名。
- 数据只存在本机浏览器（localStorage），不联网、不上传、不共享。
- 支持 PF2e 与「鼠鼠」两套检定换算：PF2e 录入 d20 结果，鼠鼠录入 2d6 / 3d6 的结果档。

## 功能

| 入口 | 内容 |
|------|------|
| 王国卡 | 属性、祸患、商品、等级进阶、专长、工地与农田、存档操作 |
| 建国 | 按王国规则分步建立王国，完成后解锁回合流程 |
| 回合 | 王国回合四阶段向导：事件、领导层、活动、结算 |
| 聚落 | 48 地块的聚落布局、建筑与加值、拥挤判定 |
| 军团 | 军队编制、装备、战争板、战术与战争动作 |
| 地图 | 六角格地图、格子索引、已占据与备注状态 |
| 查询 | 独立页面：图鉴、规则参考、战术与动作、战争关键规则、军队装备、军队等级表 |

数据规模：73 座建筑、40 个王国事件、47 个带资源的六角格、13 个王国任务。

## 快速开始

### 环境要求

- Node.js 18 及以上（建议 20 LTS）
- npm

### 安装与开发

```bash
npm install
npm run dev
```

### 构建与预览

```bash
npm run build    # 产物输出到 dist/，包含 index.html 与 query.html 两个入口
npm run preview  # 本地预览已构建的产物
```

`vite.config.js` 里 `base: './'`，构建产物可放到任意静态目录或静态服务器下使用。

### 测试

```bash
npm test
```

基于 Node 内置 `node:test`，当前覆盖成功度换算、资源骰、聚落消耗、军队维护、建筑加值、临时效果等规则计算，用例在 [rules.test.js](tests/rules.test.js)。

## 目录结构

```
├── index.html              操作台入口
├── query.html              查询页入口
├── vite.config.js          双入口构建配置
├── src/
│   ├── App.vue             页签框架
│   ├── store.js            全局状态、存档、规则计算

│   ├── style.css           设计系统变量与全局样式
│   ├── components/         各页签与查询页组件
│   └── data/               规则数据（JSON）
├── tests/rules.test.js     规则计算测试
```

`src/data/` 下的数值与文本均取自战役附录，新增数据时只加不减，保持与既有存档兼容。

## 存档

- 每次修改自动写入 `localStorage`，键名 `kingdom-sim-v1`。
- 写入前会把上一版留成滚动备份（`kingdom-sim-v1.bak`），可在王国卡里「回滚到上次自动备份」。
- 王国卡支持「导出存档」为 JSON 文件，也可从文件恢复；恢复前会先自动备份当前状态。
- 操作台与查询页共用同一份存档，`storage` 事件负责跨标签页同步。

注意：存档绑定浏览器与设备，换设备请先导出再导入。

## 规则与数据来源

- `拥王者/附录/王国与战争/`
- `拥王者/第二章/*.md`（六角格与冒险地点）
- 地图底图：`拥王者/大地图/` 下的失窃之地整页扫描

任何规则数值、建筑价格、事件文本都应以这些出处为准，不从界面反推规则。

## 已知缺口

- 受影响农田的邻接不从地图推导。
- 消耗不会自动扣减农田。
- 王国专长只有一部分接入自动计算，其余按备注在桌上处理。
