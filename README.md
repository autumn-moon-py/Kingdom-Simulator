# 失窃之地 · 战役工具

《拥王者》战役的桌边工具，分「战役地图」与「王国经营」两页。地图页做四图幅无缝拼接、格子详情、占据与备注、区域标注；王国页跑简化经营，建筑与效果都可以在界面上自定义。战争规则不在本项目内。

## 功能

- 四张图幅可任选、可全选，横向无缝拼接为一张全景
- 点格选中：侧栏显示「编号 + 区域名 + 地点名」，可写别名、勾「已探索 / 已占据」、写备注；有别名时地图标点与标题优先显示别名
- 旧存档首次升级会把「像地名的短备注」复制为别名，备注本身保留
- 普通格自动编号：有区域归属但原模组没有编号的格，按区域编号（如 `NMN6`、`GBN1`），可直接点选或输入跳转
- 自定标记：点地图落点，按 Delete 删除
- 区域显示：区域填色、区域名称，可单独开关；按区域多选筛选
- 跨图幅同一物理格联动：选中、占据、区域归属都按同一块地处理，一格不会属于两个区域
- 导出：图片与预览样式一致（含填色、区域名、占据标记、编号点）；存档可导出 JSON
- 同步飞书：按当前视图导出地图图片并写入文档「地图」章节，只写图片，手写内容保留
- 显示偏好（勾选项、区域筛选、图幅选择）记忆在本地和文件存档

### 王国经营

- 定居点槽位表：村庄 4 槽、城镇 8 槽、城市 12 槽，槽位填满后立即升级
- 按人口算出应掷的劳力骰数量，外部掷骰后把总点数填入；不记录回合数
- 建筑表可增删改：名称、别名、档位、槽位、成本、每定居点上限、临水要求与说明
- 效果类型可增删改，并映射到人口、劳力骰、p收入、物资收入、槽位或说明口径
- 新建定居点费用随定居点数量上涨；建筑、民居人口与定居点建成即生效
- 定居点可多选关联地图页中已占据的格子，选项直接读取地图存档的占据状态与备注
- 定居点别名可编辑；不记录王国等级
- 王国存档可导出 JSON、粘贴导入，或用文件导入；旧版单值地图格自动迁移为多选
- 操作记录、重置存档、自动持久化

## 存档

正式使用时用 `npm run serve` 启动 8989，地图与王国的状态会直接写到项目根目录：

- `saves/kingdom-map-v1.json`
- `saves/kingdom-manage-v1.json`

每次写入前会在 `saves/backups/` 留最多 5 份备份。换浏览器、换端口或换设备访问同一个服务，读到的都是同一份文件。localStorage 仍保留为离线兜底；服务不可用时自动退回浏览器存储。

地图状态在 localStorage 的 `kingdom-map-v1`，只包含：

`hexExplored`、`hexClaimed`、`hexNotes`、`hexAliases`、`pins`、`mapCalib`

写入时带 400ms 防抖，另有快照、5 份滚动备份和坏档留档恢复；首次打开如果只有旧版键 `kingdom-sim-v1`，会自动挑出这些字段迁移，旧键保留不删。

界面偏好另行存在 `kingdom-map-ui-v1`，与存档分开。

王国经营写入 `kingdom-manage-v1`，包含国库、物资、劳力、定居点、建筑定义、效果定义与操作记录；同样 400ms 防抖、快照与滚动备份，与地图存档互不覆盖。

## 开发

```bash
npm install
npm run dev      # 默认 http://localhost:5173/，同时开放内网访问
npm run serve    # 静态站点 + 文件存档，默认 http://localhost:8989/
npm test
npm run build
```

「同步到飞书」通过 `server.mjs` 的 `/api/feishu-sync` 调用本机 `lark-cli`；如果它不在 PATH 里，可用 `FEISHU_LARK_CLI=/绝对路径/lark-cli` 指定。同步接口只接受本机请求；图片按当前预览的图幅、区域筛选生成，只写入「地图」章节的一张地图图片，手写内容保留。

`index.html` 是唯一入口。接手开发前先看 [AGENTS.md](./AGENTS.md)。
